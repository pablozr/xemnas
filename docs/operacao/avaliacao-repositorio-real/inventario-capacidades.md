Uma avaliação completa ainda precisa preparar projetos de teste e observar a UI e os fluxos de ponta a ponta. Não executei o app nem consultei dados locais.

## Limites do inventário

Os caminhos de tela indicam entradas implementadas, mas não provam que todos estejam ligados à composição de produção em cada configuração. Para a avaliação, confirme disponibilidade pelo backend real e registre app fechado, provider ausente e projeto vazio como estados de dependência, não como falhas da capacidade. `demo_report` e a superfície `--demo` são dados de demonstração, não evidência de comportamento com dados reais. O assistente expõe briefing e rotas no código observado; este inventário não afirma que haja conversa livre com modelo.
